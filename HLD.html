Quiz Caching: Quizzes are keyed by article_set_hash (MD5 of sorted article IDs). If any user has previously generated a quiz for the same set of articles, we serve it from DB — zero LLM cost for repeat generations. The LLM is only called on first-ever generation for a given article combination.

Frontend Routes (Next.js App Router)

User Routes

  • / — News Feed (default)
  • /quiz — Select articles, generate quiz
  • /quiz/[id] — Take a quiz
  • /history — Past quizzes list
  • /history/[id] — Quiz detail + linked articles
  • /login, /register — Auth pages

Admin Routes

  • /admin — Dashboard
  • /admin/training-data — Browse AI interactions
  • /admin/datasets — Build + manage datasets
  • /admin/models — Model registry manager

Backend API (FastAPI)

Auth Endpoints

  • POST /api/auth/register
  • POST /api/auth/login
  • GET /api/auth/me

Article Endpoints

  • GET /api/articles — List (filter by date/source/topic)
  • GET /api/articles/[id] — Detail

Quiz Endpoints

  • POST /api/quizzes/generate — Create quiz from article IDs
  • GET /api/quizzes/[id] — Get quiz questions
  • POST /api/quizzes/[id]/submit — Submit answers
  • GET /api/history — User's past quizzes
  • GET /api/history/[id] — Quiz detail

Admin Endpoints

  • GET /api/admin/interactions — List AI interactions
  • PUT /api/admin/interactions/[id] — Edit/rate
  • POST /api/admin/datasets — Build dataset
  • GET /api/admin/models — Model registry
  • PUT /api/admin/models — Swap model

How this stays free at scale (for a while):
- Vercel free: 100GB bandwidth ~ 50K page views/month
- Supabase free: 500MB DB ~ 10K articles + AI interactions
- NVIDIA NIM free: 1K requests/day ~ enough for 50 daily articles + user quizzes
- Render free: Auto-sleeps when idle, wakes on request (5-10s cold start)
- Colab free: 12-15 GPU hours/week for periodic fine-tuning
- When you hit limits: Upgrade only what's needed (e.g., Supabase Pro $25/mo)
