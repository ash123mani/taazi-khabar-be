5. Quiz Caching Strategy

Why?

Every call to the LLM costs time (~5-10s) and API quota (NVIDIA NIM free tier: ~1000 req/day). If 10 different users select the same articles [A, B, C] and generate a quiz, without caching we'd call the LLM 10 times for the same output. With caching: 1 call total.

How?

1. User sends POST /quizzes/generate with article_ids = [uuid-a, uuid-b, uuid-c]
2. Backend computes: hash = MD5(sorted(["uuid-a", "uuid-b", "uuid-c"]).join(","))
   -> e.g., "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6"
3. Backend queries: SELECT id FROM quizzes WHERE article_set_hash = 'a1b2c3...'
4. If EXISTS:
     - Return existing quiz_id (no LLM call)
   If NOT EXISTS:
     - Call LLM to generate questions
     - Save quiz with article_set_hash = hash
     - Return new quiz_id
5. User-specific association:
     - quiz_articles already links quiz to articles
     - Each user's history shows the quiz via their own quiz entry
     - Multiple users can reference the same underlying questions

Database impact

- quizzes.article_set_hash: VARCHAR(32) UNIQUE NOT NULL
- No new tables needed
- Index on article_set_hash for fast lookup
- UNIQUE constraint ensures no duplicate quiz for same article set

Edge cases handled

- Same articles, different order: hash uses SORTED IDs -> same hash -> cache hit
- Same articles, different num_questions: we include num_questions in hash
  -> hash = MD5(sorted(ids).join(",") + "|" + num_questions)
- User generates quiz from articles [A,B] and later [A,B,C]: different hashes -> different quizzes
- Admin edits a cached quiz's questions: unaffected, each quiz has its own questions row

10. Scraper Design

# backend/app/scrapers/base.py

class BaseScraper(ABC):
    """Abstract scraper with common RSS pipeline."""

    @property
    @abstractmethod
    def source_name(self) -> str: ...

    @property
    @abstractmethod
    def rss_urls(self) -> list[str]: ...

    @abstractmethod
    def extract_body(self, soup: BeautifulSoup) -> str: ...

    async def run(self):
        """Called by Celery beat daily."""
        for rss_url in self.rss_urls:
            feed = await self._fetch_rss(rss_url)
            for entry in feed.entries:
                if not self._is_already_scraped(entry.link):
                    article = await self._scrape_article(entry)
                    summary = await ai_orchestrator.summarize(article.body)
                    save_to_db(article, summary)

# Respects robots.txt, rate-limited (1 req/2 sec), caches aggressively

12. Provider: NVIDIA NIM

# backend/app/ai/providers/nim.py

class NVIDIAProvider(BaseProvider):
    """Free tier: 1000 requests/day, Llama 3.1 8B"""

    BASE_URL = "https://api.nvcf.nvidia.com/v2/llm/nim"

    async def complete(
        self,
        prompt: str,
        system: str,
        max_tokens: int = 512,
        temperature: float = 0.3
    ) -> ProviderResponse:
        headers = {
            "Authorization": f"Bearer {settings.NVIDIA_API_KEY}",
            "Content-Type": "application/json"
        }
        payload = {
            "model": self.model_config.model,
            "messages": [
                {"role": "system", "content": system},
                {"role": "user", "content": prompt}
            ],
            "max_tokens": max_tokens,
            "temperature": temperature
        }
        async with httpx.AsyncClient() as client:
            resp = await client.post(self.BASE_URL, headers=headers, json=payload)
            resp.raise_for_status()
            data = resp.json()
            return ProviderResponse(
                text=data["choices"][0]["message"]["content"],
                tokens_used=data["usage"]["total_tokens"],
                latency_ms=data.get("latency", 0)
            )

    async def complete_with_lora(
        self, prompt: str, system: str, lora_adapter: str
    ) -> ProviderResponse:
        """After fine-tuning: pass LoRA adapter name in request."""
        # NVIDIA NIM supports LoRA via header: NVCF_LORA_ADAPTER
        headers["NVCF_LORA_ADAPTER"] = lora_adapter
        return await self.complete(prompt, system)

# Full notebook to be created, key steps:
